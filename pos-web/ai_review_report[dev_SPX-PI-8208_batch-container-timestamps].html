    但本次实现在 src/pages/dms/batch/current/shared.ts 明确把 updatedAt 注释为“这是 DB 行更新时间戳，只要该行任何字段被 touch 就会跳，不保证等于『移入/移除批次』这类批次操作”，随后 BatchTableShipment.tsx 又直接把这个字段渲染到 pages.dmsBatch.field.updatedTime 列，没有做任何语义校正。
