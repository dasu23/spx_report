    MAJORL162-164安全风险
    问题

    _request_host 在计算认证 Cookie 域名时优先信任 x-forwarded-host 请求头，且这里直接读取 request.headers.get("x-forwarded-host")，没有看到任何对可信反向代理来源的校验或对允许域名的白名单限制。

    随后 _cookie_domain(request) 会把这个值传给 resolve_auth_cookie_domain，并用于 _set_session_cookie / _clear_session_cookie。

    后果

    如果应用可被客户端直接访问，或上游代理未严格清洗 X-Forwarded-Host，攻击者可以伪造该请求头影响认证 Cookie 的 domain 属性，导致登录态 Cookie 被错误地下发到非预期域名、无法正确清理，甚至在共享父域场景下扩大 Cookie 作用域，增加会话泄露或会话固定风险。
