    问题

    get_pickup_route_auto_sync_config 把 SQLAlchemyError、RuntimeError、OSError 的原始异常内容直接拼到 HTTPException(detail=detail) 返回给调用方，其中 detail = str(getattr(exc, "orig", None) or exc) 会把数据库驱动报错、文件系统路径或底层运行时细节原样暴露到 HTTP 响应。

    后果

    访问 GET /auto-sync/pickup-route/config 的用户只要触发数据库异常或 I/O 异常，就能看到内部错误细节，这会泄露表名、SQL 驱动信息、文件路径或部署环境特征，降低后续针对数据库和基础设施的攻击门槛。

    怎么改

    把 detail 改成固定的业务错误文案，对原始异常只记录到服务端日志，不要回传给客户端。例如保留 409，但返回类似“配置冲突，请联系管理员”，并在日志里记录 exc_info=True。
