    MAJORL162-164权限与访问控制
    问题

    _request_host 直接信任 request.headers.get("x-forwarded-host")，并把结果传给 _cookie_domain / resolve_auth_cookie_domain 用于 _set_session_cookie 的 domain 计算；

    当前 diff 中没有看到对 x-forwarded-host 来源是否可信的校验，也没有限制只有受信反向代理才能覆盖 host。

    这意味着 POST /api/v1/auth/browser-login 设置会话 cookie 时，客户端可自行构造 X-Forwarded-Host 影响 cookie 的作用域判断。
