    .claude/settings.json 新增的 permissions.allow 同时放开了 Bash(git push:*)、Bash(openspec instructions *)、Bash(pnpm jest *)、Bash(npx jest *) 等带通配符的 Bash 执行权限，且还允许执行 Bash(npx @ai-infra/skills@latest setup) 与 Bash(npx @ai-infra/rules@latest setup) 这类直接拉取 latest 远端包的命令。
