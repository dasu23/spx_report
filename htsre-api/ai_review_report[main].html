    data/rules/section_brazil_rules.json2 Critical2 个问题
    CRITICALL181业务逻辑⚠ 行号未验证
    问题

    section_brazil_9903_05_07 的新增 description 明确写出“19 of them carry no list here ... which are not modelled, so goods exempt only through those remain dutiable”，这表示当前数据集已知缺失一部分用于豁免 section_brazil_9903_05_01 的 chapter 99 headings，但仍将该规则标记为 active 并参与正式计算。

    也就是说，规则作者已经在数据里承认存在未建模例外，却没有在执行层阻断或降级该 measure。

    后果

    当商品仅因这些“not modelled”的 passenger-vehicle 或 medium- and heavy-duty vehicle headings 才应落入 section_brazil_9903_05_07 例外时，系统不会识别该例外，最终仍可能保留 section_brazil_9903_05_01 的 25% duty。

    该问题会把已知未覆盖的法规例外静默转化为错误征税结果，属于高风险税则判定错误。

    怎么改

    在 section_brazil_9903_05_07 对应的未建模 headings 补齐 scope 数据前，不要让这组规则以“正常可计算”状态参与最终税费输出。

    可执行修复包括：补齐缺失的 19 个 headings 的 scope 建模；

    或在规则层增加 status/告警字段，使 EvaluationService 对命中相关章节时返回“无法确定，需要人工复核”，而不是继续输出确定性的 duty。

    怎么验

    构造一个 country_of_origin=BR、is_personal_baggage=false 的商品，其应仅通过 section_brazil_9903_05_07 中提到但“not modelled”的 passenger-vehicle headings 或 medium- and heavy-duty vehicle headings 获得例外。

    验证当前结果会错误保留 section_brazil_9903_05_01；修复后应改为正确豁免或返回需要人工复核。
