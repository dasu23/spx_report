    影响： 一旦生产或灰度环境遗漏 inboundSourceAppKey / inboundTargetAppKey / inboundSceneId 任一配置，持有同一 appSecret 的调用方即可绕过应用身份与场景绑定校验，向该接口发起跨应用/跨场景查询请求，扩大被信任调用方范围，形成授权边界失效。
