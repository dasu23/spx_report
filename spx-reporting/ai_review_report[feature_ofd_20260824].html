    问题

    QueryEngine._execute_doris 新增了对完整 SQL 文本和 bind 参数的调试日志输出，sql 来自模板配置，bind 来自用户查询条件，新增代码会把实际查询语句和用户输入原样写入日志。

    后果

    一旦模板查询包含客户名、账号编码、邮箱等业务敏感筛选值，或模板 SQL 本身包含受控表名/字段名，这些内容都会进入日志系统并被更广泛的运维、日志平台访问者看到，形成不必要的数据暴露面；

    在高频查询场景下还会把大量明细查询条件长期留存在日志中。

    怎么改

    删除 QueryEngine._execute_doris 中对完整 sql 和 bind 的明文调试日志，改为只记录模板标识、数据源、耗时、返回行数等低敏元数据；

    如果确实需要排障，至少对 bind 做脱敏/截断，并通过显式开关控制。
