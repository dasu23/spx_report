    MAJORL432-435权限与访问控制
    问题

    新增的 /auth/admin-login 路由没有配置 access，并且注释明确说明“gated in the page by FEATURE:AUTH:ADMIN_LOGIN because route access cannot read tenant config before sign-in”。

    这意味着路由层面对 auth/admin-login.tsx 完全放开，任何未登录用户都可以直接访问该入口，而是否拦截只能依赖页面组件内部逻辑。

    后果

    只要有人直接访问 /auth/admin-login，就能稳定触达隐藏管理员登录页的前端入口；

    如果 auth/admin-login.tsx 内部校验缺失、异步配置加载失败、或渲染早于 FEATURE:AUTH:ADMIN_LOGIN 判定，就会把本应仅对开启 FEATURE:AUTH:ADMIN_LOGIN 的租户暴露的管理员登录能力提前暴露出来，扩大认证攻击面并增加暴力尝试、枚举和社工利用风险。
